# 战术突入：撤离行动 (Tactical Assault: Extraction)

一款可在浏览器中运行的第一人称战术射击游戏（Three.js + Vite，原生 JavaScript）。
玩家突入敌方设施，完成三项任务目标（取得情报、关闭干扰设备、救出被俘人员），
击败或避开巡逻敌人，最后带着人质到达北侧撤离点才算胜利。

## 启动方式

要求：Node.js 18 以上（开发环境为 Node 22）。

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器（会自动打开浏览器 http://localhost:5173）
npm run dev

# 3. 生产构建与本地预览
npm run build
npm run preview

# 4. 运行全部单元 / 集成测试（32 个，零依赖，Node 内置测试运行器）
npm test
```

浏览器冒烟测试（需要先 `npm run dev`，另开终端）：

```bash
node tests/browser.smoke.mjs   # 自动完成一局并校验无浏览器报错
node tests/browser.shot.mjs    # 生成 tests/shot-*.png 截图
```

## 玩法目标

1. **取得情报资料**：先在设施中随机刷新的补给点找到“加密数据盘”（发光青色物体），
   再到西南资料室的终端按住 E 上传。
2. **关闭通讯干扰设备**：进入西北机房，在设备终端按住 E 三秒。
3. **救出被俘人员**：进入东北拘留室，按住 E 解开束缚，人质会跟随你移动。
4. 三个目标全部完成后，北侧撤离点（绿色信号烟雾）开启，带着人质到达即胜利。

失败条件：阵亡、8 分钟倒计时结束、人质（关键目标）被杀。

## 主要系统

- **真实射线判定**：每颗弹丸独立做射线—AABB 检测，墙体、门、箱子会挡子弹；
  命中头部/身体/四肢伤害不同；霰弹枪一次射出 8 个弹丸。
- **三种武器**：手枪、步枪、霰弹枪，伤害/射速/弹匣/备弹/换弹时间/散布/
  后坐力/射程/射击模式全部不同。
- **敌人 AI**：三种敌人（警卫、侦察兵、重装兵），具备巡逻、发现、追击、
  利用掩体、失去目标后搜索、再回到巡逻的完整状态机；视线被墙挡住时不能射击；
  全局警戒会让附近敌人扩大巡逻与搜索范围。
- **潜入与警戒**：奔跑噪音、枪声、击杀都会提高警戒；蹲下、绕行、掩体可降低暴露。
  HUD 顶部显示三档警戒等级。
- **物品背包**：医疗包、绷带、护甲、三种弹药与任务数据盘，各有不同占用格，
  总容量 8 格，可拾取、使用、丢弃；每局补给位置随机、数量有限。
- **小地图**：只显示地形、目标点、撤离点、近距离补给和正在交火/搜索中的敌人，
  不会显示全部敌人。
- **存档与设置**：3 个存档位（localStorage），主菜单“继续游戏”读取最近存档；
  支持主/音效音量、画面质量（低/中/高，影响像素比、雾、阴影）、鼠标灵敏度、
  FOV、Y 轴反转；存档损坏时有明确中文提示并可删除。
- **结算统计**：命中率、击杀数、受到伤害、用时、剩余时间、完成目标数、是否撤离。

## 项目结构

```
index.html               入口页面与所有菜单 / HUD 结构
vite.config.js           Vite 配置
src/main.js              输入、指针锁定、游戏循环、菜单与存档流程
src/core/                与渲染无关的纯逻辑（可直接单元测试）
  math.js rng.js map.js collision.js player.js enemy.js
  weapons.js items.js game.js restore.js saves.js audio.js
src/render/renderer.js   Three.js 场景、角色、武器视图模型、特效
src/ui/hud.js style.css  HUD、小地图、界面样式
tests/                   32 个 Node 测试 + 浏览器冒烟脚本
```

核心仿真逻辑不依赖 DOM / Three.js，因此移动、碰撞、射击、伤害、换弹、敌人感知、
任务完成与撤离都在 Node 中被直接测试覆盖。
