# Tactical Breach & Extract

一款在浏览器中运行的第一人称战术射击游戏（FPS）。玩家突入敌方设施，完成三项任务目标，并在时限内将人质护送至撤离点。核心玩法逻辑与 Three.js 渲染完全解耦，可在 Node 下直接单元测试。

## 启动方式

要求 Node.js 18+（已在 Node 22 上验证）。

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器，浏览器打开终端提示的地址（默认 http://localhost:5173）
```

其他命令：

```bash
npm run build      # 生产构建，输出到 dist/
npm run preview    # 本地预览生产构建
npm test           # 运行 Vitest 单元测试（15 个用例）
node tests/sim-e2e.mjs   # 无界面“整局通关”模拟（击杀→任务→撤离）
```

## 玩法

- **任务**：① 从 3 个随机机密房间之一取得加密数据盘；② 在通讯干扰器控制台前按住 E 3 秒将其关闭；③ 打开拘留室门、救出人质并护送到撤离点。全部完成后到达南门撤离圈即胜利。
- **失败**：玩家死亡、8 分钟倒计时结束、或人质死亡，结算界面会显示具体原因。
- **潜入与警戒**：蹲下移动噪声小、奔跑和开枪会显著提升设施警戒等级。敌人有巡逻 → 怀疑 → 交战 → 搜索的完整状态机，失去视线后会在最后已知位置附近搜索约 10 秒。

### 操作

| 按键 | 功能 |
| --- | --- |
| W / A / S / D | 移动 |
| 鼠标 | 视角（指针锁定） |
| Shift | 奔跑 |
| Ctrl 或 C | 蹲下（可进入低矮空间、降低被发现概率） |
| Space | 跳跃 |
| 鼠标右键（按住） | 瞄准（ADS，减小散布与视野） |
| 鼠标左键 | 开火（步枪全自动，手枪/霰弹枪半自动） |
| R | 换弹（霰弹枪逐发装填，可中断） |
| E | 开门 / 拾取 / 解救人质；在控制台前**按住**关闭干扰器 |
| 1 / 2 / 3 或 Q | 切换手枪 / 步枪 / 霰弹枪 |
| H | 使用医疗包 |
| Tab | 背包（使用 / 丢弃物品） |
| Esc | 暂停菜单（保存、设置、重开、退出） |

点击画面可重新锁定鼠标；暂停（Esc）会自动释放指针锁定，恢复后状态完整保留。

## 武器

| 武器 | 伤害 | 射速 | 弹匣 | 换弹 | 弹丸 | 有效距离 | 特点 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| M9 手枪 | 26 | 360 rpm | 12 | 1.1s | 1 | 60 | 轻量、机动好 |
| AK-74 步枪 | 24 | 600 rpm | 30 | 2.3s | 1 | 110 | 全自动、远距衰减小 |
| M870 霰弹枪 | 17×8 | 80 rpm | 6 发 | 0.55s/发 | 8 | 22 | 单发 8 弹丸、近战爆发、后坐力大 |

命中头部 ×2.4、躯干 ×1.0、四肢 ×0.65；重装兵的躯干/四肢有 55% 护甲减伤。所有弹道均为真实射线检测，墙体、门、箱子、机柜都会挡子弹。

## 物品与背包

背包 12 格：医疗包 2 格、步枪弹药 2 格、手枪/霰弹弹药 1 格、数据盘 1 格。弹药按类型堆叠、消耗独立储备；每张地图的补给点从 12 个候选位置随机抽取 8 个，数据盘位置也每局随机，不会无限刷新。

## 存档与设置

- 暂停菜单 → Save Game 可保存到 3 个存档槽，刷新浏览器后在主菜单 Continue 中读取；损坏存档会明确提示并可删除。
- 设置可调整音量、画面质量（低/中/高）、鼠标灵敏度与视野 FOV，写入 localStorage 持久化。

## 界面

HUD 含生命/护甲、当前武器与弹药、三项任务目标、警戒等级条、倒计时、撤离/目标提示、受伤红屏与方向指示、低血量脉冲警告、命中/击杀反馈、枪口火光、曳光弹和墙面火花。小地图只显示地形、任务目标和撤离点；敌人仅在已警戒且距离 16 米内时短暂出现，不会全图透视。

## 项目结构

```
index.html               所有界面（主菜单/暂停/设置/存档/背包/结算）
src/
  core/                  纯逻辑层（无 DOM / 无 Three.js 依赖，可在 Node 测试）
    math.js              向量、AABB、射线、轴分离碰撞
    map.js               地图、房间、走廊、掩体、门、随机补给/敌人
    player.js            移动、重力、碰撞、生命/护甲
    enemy.js             敌人定义、命中盒、受伤
    ai.js                视线/听觉/状态机/掩体与搜索
    weapons.js items.js  武器与背包物品
    combat.js            命中扫描（墙体 + 头/身/四肢命中盒）
    objectives.js        三个任务目标
    engine.js            游戏状态与活动碰撞体
    engine-actions.js    开火、换弹、交互、每帧更新、撤离判定
    saves.js settings.js 3 槽存档与设置（localStorage）
  render/                renderer.js（Three.js 场景/武器视图模型/特效）、minimap.js、input.js
  audio/audio.js         WebAudio 程序化音效
  main.js                界面接线、HUD、游戏循环
tests/
  core.test.js           15 个 Vitest 用例
  sim-e2e.mjs            整局通关模拟脚本
```
